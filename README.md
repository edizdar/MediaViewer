**Media Viewer**, Windows için geliştirilmiş, fotoğraflarınızı incelerken aynı zamanda videolarınızı da tek bir çatı altında oynatabileceğiniz modern, sade, hızlı ve taşınabilir (kurulum gerektirmeyen) bir masaüstü medya görüntüleyicisidir.

A fast, lightweight, and modern desktop photo and video viewer for Windows. 100% portable with zero dependencies.

## ✨ Özellikler / Key Features

### 🇹🇷 Türkçe
- 🖼️ **Fotoğraf ve Video Bir Arada:** JPG, PNG, GIF, WebP, SVG, BMP ve MP4, MOV, AVI, WebM, MKV formatları tek pencerede.
- 🖥️ **Sıfır Dikkat Dağıtıcı Tam Ekran:** Tam ekranda butonlar tamamen gizlidir. Fare sadece sağ üst köşeye (`✕ Çıkış`) veya kenarlara (`❮ ❯`) gittiğinde görünür.
- 🔍 **Merkez Odaklı Akıllı Zoom:** Ekran merkezinden simetrik yakınlaştırma/uzaklaştırma. Küçüldüğünde asla kenarda veya solda kalmaz, daima tam ortadadır.
- 🎬 **Videolarda Zoom & Klavye Gezinmesi:** Oynatılan videoyu fare tekerleğiyle yakınlaştırın ve görünmeyen yerleri yön tuşlarıyla (`← → ↑ ↓`) kaydırarak inceleyin.
- 🎨 **Dahili Işık / Renk Ayarları (`Ctrl + J`):** Karanlık fotoğrafları tek tıkla aydınlatmak için Parlaklık, Kontrast ve Gamma ayarları.
- 📋 **Özel Oynatma Listeleri (`Ctrl + L`):** Medyaları sıraya dizin, listeleri kaydedin (`.mvpl`) ve açın.
- ⚡ **Taşınabilir (Portable):** Kurulum yok, tek dosya `.exe`. USB'de veya masaüstünde hemen çalışır.

### 🇬🇧 English
- 🖼️ **All-In-One Hub:** Supports JPG, PNG, GIF, WebP, SVG, BMP, and MP4, MOV, AVI, WebM, MKV under one roof.
- 🖥️ **Distraction-Free Fullscreen:** Pure borderless view. Controls only pop up when hovering specific corner/edges (`✕ Exit`, `❮ ❯` Nav).
- 🔍 **Center-Focused Smooth Zoom:** Symmetrical zooming from screen center. Never drifts off-center when shrinking.
- 🎬 **Video Zoom & Arrow Key Pan:** Zoom into playing videos and navigate hidden areas using arrow keys (`← → ↑ ↓`).
- 🎨 **Real-Time Color Correction (`Ctrl + J`):** Rescue dark or underexposed photos with Brightness, Contrast, and Gamma sliders.
- 📋 **Custom Playlists (`Ctrl + L`):** Create, save, and load `.mvpl` sequential playlists.
- ⚡ **100% Portable:** Single executable file. No installation or admin privileges needed.

## ⌨️ Kısayollar / Keyboard Shortcuts

| Kısayol / Shortcut | İşlev (TR) | Function (EN) |
| :--- | :--- | :--- |
| **`←` / `→`** | Önceki / Sonraki Medya | Previous / Next Media |
| **`F11` / Çift Tık** | Tam Ekran Aç / Kapat | Toggle Fullscreen |
| **`Esc`** | Tam Ekrandan Çık | Exit Fullscreen |
| **`Space`** | Video: Oynat/Duraklat • Foto: Sonraki | Video: Play/Pause • Photo: Next |
| **`Ctrl + J`** | Renk Ayarları Paneli | Color Adjustments Panel |
| **`Ctrl + L`** | Oynatma Listesi Paneli | Playlist Panel |
| **`Ctrl + +` / `Ctrl + -`** | Yakınlaştır / Uzaklaştır | Zoom In / Zoom Out |
| **`Ctrl + 0`** | Orijinal Boyut (%100) | Original Size (100%) |
| **`Ctrl + F`** | Pencereye Sığdır | Fit to Window |
| **`R` / `Shift + R`** | Sağa / Sola 90° Döndür | Rotate 90° Clockwise / CCW |
| **`Delete`** | Çöp Kutusuna Gönder | Move to Recycle Bin |
